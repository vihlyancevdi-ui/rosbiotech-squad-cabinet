# Личный кабинет студенческих отрядов РОСБИОТЕХ

Стартовый MVP на Node.js + Express + PostgreSQL.

## Функции
- Регистрация и вход по email и паролю.
- Роль администратора для email из `BOOTSTRAP_ADMIN_EMAIL`.
- Профиль и выбор нескольких отрядов с основным отрядом.
- Общие и отрядные мероприятия, запись и просмотр деталей.
- Загрузка грамот и просмотр/скачивание.
- Общий рейтинг и рейтинг отрядов.
- Администрирование: создание отрядов/мероприятий, управление ролями и баллами, отметка посещения.

## Локальный запуск
1. Установите Node.js 20+ и PostgreSQL.
2. Создайте БД и задайте `DATABASE_URL`.
3. Задайте `SESSION_SECRET` и `BOOTSTRAP_ADMIN_EMAIL`.
4. Выполните `npm install`, затем `npm start`.
5. Откройте `http://localhost:3000`.

## Railway
1. Загрузите файлы архива в отдельный GitHub-репозиторий.
2. Подключите репозиторий в Railway как сервис.
3. Добавьте PostgreSQL и убедитесь, что переменная `DATABASE_URL` доступна приложению.
4. Установите `SESSION_SECRET` и `BOOTSTRAP_ADMIN_EMAIL`.
5. Для постоянного хранения загруженных файлов добавьте Railway Volume и смонтируйте его в `/app/uploads`.
6. После первого входа администратора измените/удалите `BOOTSTRAP_ADMIN_EMAIL`.

## Важное ограничение
Это MVP для проверки основных сценариев, не production-система для персональных данных. Пока не реализованы подтверждение почты, восстановление пароля, CSRF-защита, ограничение частоты запросов и антивирусная проверка загрузок. Перед реальным использованием доработайте безопасность, согласие на обработку персональных данных и хранение файлов. Не коммитьте `.env` и реальные пользовательские данные.
